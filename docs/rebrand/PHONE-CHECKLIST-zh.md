# PetroCASH Android 首轮手机测试

只在下载链接、APK SHA-256、applicationId/version和签名已核对后开始。当前交接中的“编译成功”不代表有可用文件；不要下载旧io.metamask基线替代PetroCASH。

## 安装前

- 核对APK是org.petrocash.wallet、1.0.0/code1，实际hash与交付记录相同；证书以本次artifact-metadata/apksigner输出为准。当前预期TEST公用证书6f9f444af1cb1ff7c0d7791af2e775fddf4d48900642647640e225783554ecf9，不是正式生产签名。
- 首轮使用新建的空测试钱包，不导入现有SRP/私钥，不存真实资金。助记词只由你私下备份，不发聊天、日志或截图。
- 保留官方MetaMask(io.metamask)。新org包应共存；遇到冲突先记录已安装包名/版本/证书，不盲目卸载任何钱包。工作资料不能绕过同包名签名约束。
- 记录Android版本、手机型号、RAM、安装来源、APK hash、测试时间与构建commit。一天后备artifact会过期，及时保存本地。

## 安装与启动

1. 点击安装，确认桌面名称/图标为PetroCASH，官方MetaMask仍在。
2. 完全关闭网络后冷启动，确认本地欢迎/解锁界面仍绘制，网络服务失败有明确状态，不白屏或循环加载。
3. Wi-Fi启动，创建新的空测试钱包，检查密码校验、SRP确认、备份流程、错误消息和返回按钮。不要跳过安全步骤。
4. 锁定、正确/错误密码解锁、系统返回、旋转/字体放大、导航栏手势和三按钮模式分别检查；助记词界面禁止截图。
5. 切后台10秒后返回，强制结束后重开，确认加载装饰不会卡住或提前进入钱包，原锁定/认证规则仍生效。

## 品牌与无障碍

- 欢迎、登录、创建、手动备份和VBA等待界面检查原创标志/动效；不应显示被替换的狐狸。其他功能动画若仍出现狐狸，记录页面/操作，不把所有binary判作已清除。
- 系统“移除/减少动画”开启后冷启动，标志保持静态；开启飞行模式时静态本地图仍可见。切后台时不继续运动。
- 大字体/屏幕阅读器下按钮和错误文案可读，不裁切；装饰图不抢焦点，加载状态仍被读出。
- 深浅主题检查主色、对比度、Inter字体、金额排版、小屏与底部安全区。

## 功能回归（逐项记录PASS/FAIL/BLOCKED）

- 网络列表、地址复制、账户添加/切换、代币/NFT列表、搜索、接收二维码与扫描。
- 内置浏览器访问自选公开DApp，核对显示身份；连接请求先拒绝，再只连接空测试账户；断开后权限确实移除。
- WalletConnect扫码/深链配对、petrocash://返回、拒绝签名、取消请求、断开及重启恢复。未实际完成不得勾PASS。
- Polygon网络显示、余额/RPC错误、添加网络确认、网络切换。WAL001–007/POL001–010按docs/petro/ACCEPTANCE.md另行记录；不把UI能打开当链上验收。
- 买卖/桥/卡/银行/Perps等仅检查入口、文案和服务可用状态；实际资金/交易/签名另需具体授权。Firebase测试派生身份的OAuth/push/attestation预期未注册，记录BLOCKED或真实错误。
- 支持/条款/隐私/官网链接打开正确目标；自有网站未部署时记录失败，不能作为已完成的法律页。
