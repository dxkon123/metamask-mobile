1. Verify and install
   Compare the APK SHA-256 with APK-SHA256.txt before installation. Use a spare
   physical device or clean emulator with no official io.metamask installed in
   ANY user/profile. A work profile, guest or second Android user is not a
   signature-conflict workaround: Android shares package code across users.
   This development package uses
   io.metamask and the upstream public development certificate; it cannot update
   an official MetaMask installation signed with another certificate. To coexist
   on your existing phone, a future separately authorized package-ID rebrand
   and rebuilt APK are required; neither is done in this step. Preserve
   your existing wallet application and data. Confirm installation and launch,
   version information, and absence of immediate crashes.

   Before connecting: review PETRO-Preinstall-Security-Review.md. The build is
   network-capable, uses upstream production AND development service hosts,
   retains Segment initialization, and has open critical build-chain findings.
   Native-library vulnerability absence and runtime egress are NOT cleared.

2. Create a fresh disposable wallet (WAL-001)
   Generate a new wallet in the app. Verify the recovery phrase privately;
   never photograph, upload or paste it into chat. Record only the public
   address. Lock/unlock, force-close/reopen and reboot the phone. Confirm the
   same address, account and authenticated access persist.

3. Import and recover (WAL-002)
   In a separate fresh test installation on a compatible spare device/emulator,
   privately import only the
   disposable test phrase and verify the expected public address. Test the
   supported private-key import using a key from this disposable test wallet.
   Verify lock/restart persistence. Never import a production wallet.

4. Add and switch accounts (WAL-003)
   Add two derived accounts, verify distinct addresses, switch between them,
   restart, and recover the same derived accounts privately from the test phrase.

5. Export authentication (WAL-004)
   Check that a wrong password prevents private-key display. Authenticate through
   the original export interface, verify the selected account, and privately
   verify that importing its exported key recovers that public address. Do not
   capture the key or share it. UI checks alone do not prove absence of secret
   logging or network transmission; instrumented security review remains open.

6. Polygon network and assets (POL-001, POL-002, POL-005)
   Select Polygon Mainnet, chain ID 137, native token POL. Compare the public
   address and balance with PolygonScan. Check supported token chain, address,
   symbol, decimals and displayed balance. Confirm another network can be
   selected and switching back restores the correct Polygon account state.

7. Original Web3 Browser (WAL-007, POL-007)
   Open https://quickswap.exchange in the app's original Web3 Browser. Review
   the origin and requested permissions, connect the disposable wallet, and
   verify its public address and Polygon network. Review network switching and
   a genuine quote for a supported pair. Loading, connecting or quoting alone
   does not pass WAL-007.

9. Complete the DEX transaction (WAL-007, POL-008, POL-009)
   Leave BLOCKED until you approve the actual pair, input amount, token/DEX

   A reverted transaction is FAIL; a quote without a completed swap is BLOCKED.
